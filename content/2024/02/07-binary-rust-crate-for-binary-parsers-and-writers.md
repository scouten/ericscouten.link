binrw is a Rust crate that uses declarative attributes on ordinary structs and enums to generate binary parsers and writers, with support for endianness, conditional fields, and custom encodings. If you've ever hand-rolled byte-offset math for a file format or network protocol, this is a much safer and more readable way to do it.
