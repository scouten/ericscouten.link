MarkChart is a native Mermaid diagram editor for iPhone, iPad, and Mac, with live preview, syntax highlighting, an interactive visual canvas, templates, and Quick Look support for .mmd files. Handy if you write flowcharts, sequence diagrams, or Gantt charts as text and want polished PDF/PNG/SVG exports without a browser-based tool.
