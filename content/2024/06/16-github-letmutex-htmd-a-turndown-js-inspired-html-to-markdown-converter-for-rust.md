htmd is a Rust crate for converting HTML to Markdown, modeled closely on turndown.js — it offers the same rich set of options and passes turndown's test suite. Handy if you need reliable HTML-to-Markdown conversion in a Rust pipeline without shelling out to a JavaScript runtime.
