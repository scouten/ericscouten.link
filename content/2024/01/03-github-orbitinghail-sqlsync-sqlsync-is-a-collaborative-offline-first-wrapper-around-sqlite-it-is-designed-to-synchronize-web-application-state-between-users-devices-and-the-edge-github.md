via [Axel Rauschmayer (@rauschma@fosstodon.org)](https://fosstodon.org/@rauschma/111694685586161588): Two projects that sync in-browser SQLite databases with servers:

SQLSync is a collaborative, offline-first wrapper around SQLite that syncs web application state between users, devices, and the edge. Written in Rust and compiled to WASM, it brings reactive query subscriptions and automatic conflict resolution to local-first apps without requiring you to hand-roll a sync layer.
