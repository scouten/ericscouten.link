Ryan Trimble shares a handful of VS Code plugins he's used so long he forgot they weren't built-in — Markdown All in One (paste a URL over selected text to make a Markdown link), Better Comments for highlighted TODO/alert annotations, and Peacock for color-coding windows per workspace. Handy if you do a lot of Markdown authoring or juggle many projects at once.
