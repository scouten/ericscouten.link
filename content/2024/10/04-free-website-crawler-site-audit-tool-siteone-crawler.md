via [Alexis Jacomy (@jacomyal@vis.social)](https://vis.social/@jacomyal/113247984057416458): Just found out about SiteOne Crawler: https://crawler.siteone.io

SiteOne Crawler is a single dependency-free binary that deep-crawls any site and produces an interactive audit report covering SEO, security headers, accessibility, performance, and broken links. It can also mirror a site for offline use, generate sitemaps, or convert pages to clean Markdown / llms.txt for feeding to an LLM. Available as a desktop GUI or a CLI with roughly 200 options, so it slots nicely into a CI/CD quality gate.
