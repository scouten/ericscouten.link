via [Axel Rauschmayer (@rauschma@fosstodon.org)](https://fosstodon.org/@rauschma/112463815225347052): Monolith lets you download a complete web page as a single HTML file—by inlining images etc.

Monolith is a Rust CLI tool that bundles an entire web page — CSS, images, JavaScript, fonts and all — into a single self-contained HTML file with no external dependencies. A handy way to archive pages that might not survive the next site redesign or link rot purge.
