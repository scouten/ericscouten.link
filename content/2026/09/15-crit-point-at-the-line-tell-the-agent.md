Crit is a local, browser-based review surface for AI agent output: point at line 47 of the diff, type "this drops the refresh token," and the agent picks up the comment and fixes it. Beyond code diffs it also handles plans and docs, running dev servers, and static HTML artifacts — each of which terminal scrollback handles badly. Self-hostable and works with git, jj, and sapling.
