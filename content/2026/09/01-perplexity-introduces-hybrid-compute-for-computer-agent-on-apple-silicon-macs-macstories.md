via [John Voorhees (@johnvoorhees@macstories.net)](https://mastodon.macstories.net/@johnvoorhees/117196426976615094): Hybrid compute for Perplexity's Personal Computer is an exciting development that runs on Apple silicon Macs and blends cloud-based frontier models with local AI. Details on MacStories.

Perplexity's new "hybrid compute" runs agent tasks in the cloud by default, but a local classifier flags potentially sensitive data and offers to route that portion to a model running on your Apple silicon Mac — and it works for sessions started from an iPhone or iPad, too. Data privacy is the next big blocker for agentic tools in regulated industries, so it's good to see someone tackling it directly rather than asking customers to trust a cloud endpoint.
